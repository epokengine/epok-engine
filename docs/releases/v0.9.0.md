# Epok Engine v0.9.0

This release adds verified PS-EXE exports, scenes stored outside the executable,
the Dungeon Complete game template, controller rumble and 2D backgrounds and
foreground masks composed with a 3D world. It also improves serial Play,
PocketStation transfers, runtime performance and editor workflows.

## PS-EXE exports and external scenes

- Use **Build > Export PS-EXE...** or `--export-ps-exe` to package a whole game,
  the current scene or selected scenes for a PCDrv-compatible loader. The ZIP
  contains the verified executable, required geometry and scene files, a
  manifest, launch instructions, licenses and optional debug symbols.
- Export checks payload hashes before replacing an existing package. Repeating
  an unchanged export reuses the build and reproduces the ZIP byte for byte.
  The project's saved Play profile stays unchanged.
- Include an optional performance overlay that starts hidden and toggles with
  **Select**. XA music and video used by the selected content stop a PS-EXE
  export with a diagnostic; they require a CD build.
- Choose **In EXE** per scene in **Project Settings > Maps & Build**. External
  scenes load from `SCENEnn.BIN` through CD or PCDrv into one RAM region sized
  for the largest scene. Scripts and engine code remain resident.
- External startup scenes load behind the boot screen. File size and checksum
  checks reject missing, damaged or mismatched scene data and offer **START**
  to retry. Memory reports account for the shared region and individual files.

See [Export PS-EXE](../ps-exe-export.md) and
[Scenes outside the executable](../scene-files.md).

## Dungeon Complete and controller feedback

- Create the finished Reactor Station action game from **Dungeon Complete**:
  enemies, a boss, camera-relative controls, inventory, healing items, upgrades,
  persistent trading, MIDI music and the Asteroid Catcher PocketStation game.
  Its C++ gameplay and PocketLua sources remain editable.
- Transfer PocketStation mining rewards into the game's economy, with saved
  progress and receipts that prevent duplicate collection.
- Request timed controller rumble from C++, Blueprint or Lua, inspect support
  and status, and cancel or disable output per logical pad. Desktop device
  assignment and a short test pulse are available in Controls settings.
- Dungeon Complete adds damage borders and short vibration. The bundled
  Controller Rumble example exercises individual motors, pad routing, scene
  changes and cancellation.

See [Project templates](../projects.md#dungeon-complete),
[Controller rumble](../input-collision.md#controller-rumble) and
[PocketStation development](../pocketstation.md).

## 2D composition and editor workflows

- Draw a `CanvasLayer2D` **Under 3D** for a background behind world geometry.
  Use `Depth2D` sprites and tile layers as foreground masks at a camera distance
  or the depth of a 3D anchor, allowing characters to walk behind cut-outs.
- Preview the composition in PSX and Native PC Play. The editor warns about
  missing cameras, invalid anchors, unsupported drawables and split screen.
- Create configured 3D objects, lights, audio sources, effects, colliders,
  cameras and UI widgets from the Hierarchy and GameObject menus.
- Create children directly from an actor's menu, select multiple actors in
  the Hierarchy and use **Select Children**. Creation switches to the relevant
  scene view and participates in Undo/Redo.
- Improve free-orbit orientation controls and viewport navigation.

See [2D and the 3D world](../2d.md) and [The editor](../editor.md).

## Runtime reliability and maintenance

- Reduce PSX frame spikes and make PocketStation recovery waits asynchronous,
  allowing rendering and music to continue while the device becomes ready.
- Improve serial streaming and music reliability, report serial runtime faults
  in Console, and support reset recovery and reconnection.
- Improve Native PC scene lifecycle, spatial queries, transform caching,
  rendering and music timing.
- Update the pinned Nugget SDK with its MSVC fixed-point conditional fix.
  Restore the default formatting, test, strict Clippy and debug-build checks.
- Regenerate the API reference and gameplay parity coverage against the pinned
  SDK, excluding preprocessor directives from displayed declarations.

## Compatibility and boundaries

- `VERSION`, the editor package and all shipped project descriptors advance to
  **0.9.0**. Open older projects through the Hub's confirmed upgrade, which backs
  up the descriptor; headless open paths reject a mismatched editor version.
- New projects default to external scenes. Older projects retain resident
  scenes until their scene table is edited. External scene files require CD or
  PC-on-demand data; Native PC Play and PsyQo source exports keep scenes resident.
- Dungeon Complete offers its C++ game and PocketLua app; standalone Blueprint
  and Lua variants of the complete game are unavailable. Starter templates
  retain their existing gameplay language choices.
- Native PC rumble depends on the host device backend and is unsupported on
  macOS with the current dependency. PSX pad routing uses the first controller
  socket, directly or through its multitap.
- Native PC depth composition compares pixels; the PSX orders whole polygons.
  SplitScreen2D keeps masked nodes on their ordinary canvas.
- On Windows, the pinned psxavenc 0.3.1 encoder produces invalid XA audio
  metadata for the stereo AVI used in release validation. Import rejects it
  with `Video audio must be 4-bit XA-ADPCM`; the final PS-EXE video-exclusion
  acceptance check therefore remains unverified. The installed encoder matches
  the checksum-verified distribution. This importer and encoder pin also shipped
  in v0.8.0.
- The downloadable distribution remains Windows x64 Portable. Emulator checks
  do not establish physical-console timing or compatibility with every loader.
