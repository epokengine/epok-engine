# Epok Engine v0.8.0

This release adds PocketStation development, full-motion video, an integrated
code editor and asset DataTables, alongside improvements to audio previews,
dungeon rendering and the Content browser.

## PocketStation and PocketLua

- Create PocketStation app assets with PocketLua or ARM/Thumb assembly, sprites,
  animated icons and memory-card metadata. Start with Star Catcher, an empty
  PocketLua app or an assembly program.
- PocketLua is a statically checked Lua subset compiled by Epok to native Thumb
  code. Its compiler and assembler are included in the editor.
- Build and run apps on the embedded PocketStation emulator, inspect variables
  and registers, step through source, and export programs for the device.
- Install, start and exchange messages and shared values with apps from C++,
  Blueprint or Lua. Play connects the editor's PocketStation to PCSX-Redux.

See [PocketStation development](../pocketstation.md).

## Full-motion video

- Import videos with configurable picture size, frame rate, audio, compression
  and brightness. Import validates frames with the console's decoder.
- Preview the decoded clip in the editor and play it from C++, Blueprint or Lua.
  Console playback streams from CD using MDEC video and XA audio; gameplay
  resumes when the clip finishes or is skipped.

See [Full-motion video](../video.md).

## Integrated code editor

- Edit gameplay Lua, C++ and embedded PocketLua sources in the bundled Monaco
  workspace, with tabs, a source tree, diagnostics and navigation.
- Install or select Lua Language Server and clangd for completion, hover,
  definitions, references, rename and formatting using Epok's project APIs.
- Optional GitHub Copilot support adds inline suggestions and chat through the
  official language server. It requires GitHub sign-in and a Copilot entitlement.
- Save All includes source buffers; saves detect external file changes and
  refuse to overwrite them. PocketStation source saves back into its app asset.

See [Integrated code editor](../code-editor.md).

## Asset DataTables

- Create portable tables of string keys and persistent asset references. Choose
  a single asset type, such as AudioClip for sound effects, or use a mixed table.
- Edit rows with Undo/Redo, add matching project assets, and locate references
  with the magnifying-glass button in the Project browser.
- Find assets by key and perform checked casts from C++, Blueprint and Lua.
  Reachable rows and nested tables are included when cooking a game.
- Validation reports duplicate keys, missing references and type mismatches.
  Missing runtime keys or unsuccessful casts return an empty reference.

See [Asset DataTables](../data-tables.md).

## Rendering, audio and editor improvements

- Improve dungeon performance, collision queries and live lighting previews.
- Seal coplanar dungeon seams at grazing camera angles while preserving baked
  lighting, and correct geometry projection and frustum edge cases.
- Reuse prepared audio when replaying previews and explain playback blockers
  before starting a preview.
- Group Content browser creation actions into styled submenus and show pause
  and frame-step controls during Play.
- Reduce dependency debug symbols in development builds while retaining
  debugging for workspace code.

## Compatibility and boundaries

- The downloadable package is Windows x64 Portable. PSX builds require the
  project-owned setup tools described in the README.
- PocketLua uses 32-bit integers and fixed data structures. The PocketStation
  emulator currently has no audible speaker output or infrared support.
- Full-motion video requires CD-on-demand data and pauses gameplay during
  playback. Import and preview do not replace testing the final disc build.
- DataTable changes require rebuilding the game; editing a table does not
  replace assets in a running session. Lua lookup keys and kinds are literals.
- Emulator verification does not establish physical-console timing or hardware
  compatibility.
