# Third Person arena — level placeholder

An editable low-poly arena with grey platforms, ramps, blue cubes and a static mannequin.
Open the scene, explore with right mouse + WASD, or edit a mesh through the Blockout panel.
Play renders a static overview on PSX. Character movement, camera following and collision
behaviours are not attached. The editor also provides an FBX skeletal import/animation
pipeline; this template uses a static placeholder.

All geometry is generated locally as Epok assets. Curves use a small number of flat
segments, and the grid uses vertex-colored geometry. Each area has a separate editable
mesh package and named face groups. Materials can also use imported textures.
